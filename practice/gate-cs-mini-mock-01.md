# GATE CS Mini Mock 01

**Time:** 45 minutes. **Questions:** 20. This is an original short mixed practice set, not a full GATE paper. Use the current official pattern for full-length mocks. Try first without notes.

## Questions

1. The proposition p→q is equivalent to:
   A. p∧q  B. ¬p∨q  C. p∨¬q  D. ¬p∧q

2. Number of ways to choose 2 objects from 5 when order does not matter:
   A. 10  B. 20  C. 25  D. 5

3. The determinant of [[2,1],[5,3]] is:
   A. 1  B. 6  C. 11  D. −1

4. Three fair coin tosses are made. Probability of exactly two heads:
   A. 1/8  B. 3/8  C. 1/2  D. 3/4

5. For Boolean inputs A,B, F=A'B+AB' is:
   A. A AND B  B. A OR B  C. A XOR B  D. A XNOR B

6. A processor has base CPI 1, miss rate 0.02 per instruction, and miss penalty 50 cycles. Ignoring other costs, CPI is:
   A. 1.02  B. 2  C. 50  D. 3

7. Which condition is required for ordinary binary search?
   A. Sorted input  B. No repeated values  C. A tree representation  D. Hashing

8. Merge sort has asymptotic worst-case time:
   A. O(log n)  B. O(n)  C. O(n log n)  D. O(n²)

9. In an undirected connected weighted graph, a minimum spanning tree on n vertices has:
   A. n edges  B. n−1 edges  C. n+1 edges  D. 2n edges

10. The language generated by S→aSb | ε is:
    A. all strings over {a,b}  B. {aⁿbⁿ | n≥0}  C. {aⁿbᵐ | n,m≥0}  D. finite

11. A predictive top-down parser cannot directly handle a grammar with:
    A. terminals  B. left recursion  C. epsilon productions  D. multiple nonterminals

12. Which phase typically produces tokens such as identifier, integer literal, and keyword?
    A. Lexical analysis  B. Register allocation  C. Linking  D. Code scheduling

13. Round Robin scheduling assigns each ready process a bounded:
    A. page frame  B. time quantum  C. disk cylinder  D. hash slot

14. A relation is in Second Normal Form when it is in 1NF and has no:
    A. foreign key  B. partial dependency of a non-key attribute on part of a candidate key  C. join  D. index

15. An IPv4 /26 block contains how many total addresses?
    A. 32  B. 64  C. 128  D. 256

16. Receiver-advertised TCP window primarily communicates:
    A. receiver buffer capacity available for flow control
    B. router table size
    C. DNS cache duration
    D. Ethernet collision count

17. A 20% price increase followed by a 20% decrease gives a net:
    A. 0% change  B. 4% decrease  C. 4% increase  D. 20% decrease

18. Choose the grammatically correct sentence:
    A. Each of the files are checked.
    B. Each of the files is checked.
    C. Each files is checked.
    D. Each of file are checked.

19. Rotate point (2,3) by 90 degrees clockwise about the origin:
    A. (−3,2)  B. (3,−2)  C. (−2,−3)  D. (2,−3)

20. A passage says: “The trial reduced average delay on two routes; it did not measure other routes.” Which conclusion is supported?
    A. Delay fell on every route.
    B. The trial reported lower average delay on the two measured routes.
    C. The method always improves traffic.
    D. The trial proves causation everywhere.

## Answers and explanations

1. **B.** An implication is false only when p is true and q false; ¬p∨q has exactly that truth table.
2. **A.** C(5,2)=5×4/(2×1)=10.
3. **A.** 2×3−1×5=1.
4. **B.** Three outcomes out of eight have exactly two heads.
5. **C.** XOR is 1 when inputs differ; these two product terms encode that.
6. **B.** CPI=base CPI + miss rate×penalty = 1+0.02×50=2.
7. **A.** Sorted order justifies discarding half after each comparison.
8. **C.** Merge sort satisfies T(n)=2T(n/2)+Θ(n)=Θ(n log n).
9. **B.** A spanning tree connects all n vertices without cycles and has n−1 edges.
10. **B.** Each recursive step adds one a before and one b after; ε is the n=0 case.
11. **B.** Left recursion can cause a predictive top-down parser to loop; transform the grammar first.
12. **A.** The lexer groups characters into token categories.
13. **B.** A quantum bounds one turn before preemption and requeue.
14. **B.** 2NF removes partial dependencies on part of a composite candidate key.
15. **B.** 32−26=6 host bits, so 2⁶=64 total addresses.
16. **A.** The advertised receive window supports receiver-side flow control; congestion control is separate.
17. **B.** 1.2×0.8=0.96, so the final price is 4% below the start.
18. **B.** Each is singular.
19. **B.** Clockwise rotation maps (x,y) to (y,−x).
20. **B.** The conclusion must stay within the two routes measured; the passage does not prove broad causation.
