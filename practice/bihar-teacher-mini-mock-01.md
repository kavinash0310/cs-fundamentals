## Questions

### General Studies

1. How many three-digit positive integers are divisible by 5?
   A. 180  B. 200  C. 160  D. 90

2. A loss is 10% of selling price. The loss as a percent of cost price is:
   A. 10%  B. 9 1/11%  C. 11%  D. 8%

3. A traveller covers 60 km at 30 km/h and 60 km at 60 km/h. Average speed for the whole trip is:
   A. 45 km/h  B. 40 km/h  C. 30 km/h  D. 35 km/h

4. Which river is a major tributary system entering the Ganga from the north in Bihar?
   A. Gandak  B. Narmada  C. Tapi  D. Godavari

5. Which category of the Constitution contains rights enforceable by courts, subject to constitutional limits?
   A. Directive Principles  B. Fundamental Rights  C. Fundamental Duties  D. Cabinet conventions

6. Which cell structure is the primary site of photosynthesis in green plants?
   A. Mitochondrion  B. Chloroplast  C. Ribosome  D. Nucleus

7. All teachers are readers. No reader is careless. Which conclusion follows?
   A. All readers are teachers.  B. No teacher is careless.  C. Some careless people are teachers.  D. All careful people are teachers.

### Computer Science

8. A compiler converts a source program into:
   A. only a flowchart  B. target/object code after translation  C. a database schema  D. a network address

9. A NAND gate outputs 0 only when:
   A. both inputs are 0  B. exactly one input is 1  C. both inputs are 1  D. inputs differ

10. An ordinary IPv4 /27 subnet has how many usable host addresses?
    A. 14  B. 30  C. 32  D. 62

11. Which data structure removes the most recently inserted item first?
    A. Queue  B. Stack  C. Heap only  D. Adjacency list

12. Breadth-first search in an unweighted graph typically uses a:
    A. stack  B. queue  C. hash function  D. recursion-only call

13. Which set contains the four Coffman conditions for deadlock?
    A. Mutual exclusion, hold-and-wait, no preemption, circular wait
    B. Race, starvation, paging, fragmentation
    C. Mutual exclusion, caching, polling, DMA
    D. Atomicity, consistency, isolation, durability

14. Which SQL clause filters grouped results after aggregation?
    A. WHERE  B. HAVING  C. ORDER BY  D. DISTINCT

15. In IPv4 fragmentation, the fragment offset is measured in units of:
    A. 1 byte  B. 4 bytes  C. 8 bytes  D. 16 bytes

16. Which sequence is the TCP three-way handshake?
    A. ACK, FIN, SYN  B. SYN, SYN-ACK, ACK  C. SYN, ACK, FIN  D. FIN, FIN-ACK, ACK

17. Compaction primarily addresses:
    A. internal fragmentation  B. external fragmentation  C. CPU scheduling  D. deadlock

18. In C, if p points to an integer x, what does *p denote?
    A. the address of p  B. the integer value stored at the pointed-to location  C. the size of x  D. a function call

19. Binary search requires the input to be:
    A. sorted  B. a linked list only  C. unique  D. stored in a database

20. A digital signature is verified using the signer's:
    A. private key  B. public key  C. password  D. symmetric session key

## Answer key and reasoning

1. **A.** Hundreds digit has 9 choices, tens digit 10, units digit 2: 9×10×2=180.
2. **B.** If SP=100, loss=10, CP=110. Loss/CP=10/110×100=9 1/11%.
3. **B.** Times are 2 h and 1 h, so total 120 km/3 h=40 km/h. Do not average segment speeds.
4. **A.** Gandak is one of the north-bank tributary systems of the Ganga in Bihar.
5. **B.** Fundamental Rights are judicially enforceable, subject to limits and procedures.
6. **B.** Chloroplasts contain chlorophyll and carry out photosynthesis.
7. **B.** Teachers are a subset of readers, and readers are disjoint from careless people.
8. **B.** A compiler translates source through phases and emits target/object code; implementation details vary.
9. **C.** NAND is NOT-AND; AND is 1 only for two 1s, so NAND is 0 there.
10. **B.** 32 address values total; in a normal subnet network and broadcast are reserved, leaving 30.
11. **B.** Stack is LIFO.
12. **B.** A queue explores vertices in increasing distance layers.
13. **A.** All four are required for the classical Coffman deadlock characterization.
14. **B.** HAVING filters groups; WHERE filters rows before grouping.
15. **C.** IPv4 offsets use 8-byte units.
16. **B.** Client SYN, server SYN-ACK, client ACK.
17. **B.** Compaction joins scattered free holes to reduce external fragmentation.
18. **B.** Dereferencing p gives the pointed-to integer value.
19. **A.** Ordering lets each comparison discard half the range.
20. **B.** The public key checks a signature created with the corresponding private key; signatures do not provide secrecy.
