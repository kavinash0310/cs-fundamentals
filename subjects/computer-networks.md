# Computer Networks

A layered route from link communication through IP, transport, applications, and security basics.

## Chapter sequence

| Chapter | Coverage |
|---|---|
| [1. Layering, switching, and performance](computer-networks/chapter-01-layering-switching-and-performance.md) | Encapsulation, switching, delay, throughput, bandwidth-delay product |
| [2. Data link, error control, and LANs](computer-networks/chapter-02-data-link-error-control-and-lan.md) | CRC, reliable transfer, windows, Ethernet, Wi-Fi MAC |
| [3. IP, addressing, fragmentation, and routing](computer-networks/chapter-03-ip-addressing-fragmentation-and-routing.md) | CIDR, subnetting, NAT, fragmentation, distance-vector/link-state |
| [4. UDP, TCP, flow, and congestion](computer-networks/chapter-04-transport-tcp-udp-and-congestion.md) | Ports, sockets, reliability, sequence/ACK, flow vs congestion control |
| [5. DNS, HTTP, security, and review](computer-networks/chapter-05-dns-http-security-and-review.md) | DNS, HTTP/HTTPS, TLS, certificates, authentication and signatures |

The extra Wi-Fi/security material supports teacher and interview preparation; use the official [GATE CS network syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf) as the exam scope.
