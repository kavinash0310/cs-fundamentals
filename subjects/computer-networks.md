# Computer Networks

## Topics

- Layering and the roles of common network protocols.
- Ethernet, Wi-Fi, switching, and basic LAN concepts.
- IP addressing and subnetting; IPv4 and IPv6; routers and routing.
- TCP and UDP, ports, sockets, flow control, and congestion control.
- DNS, HTTP/HTTPS, email protocols, and client-server communication.
- Error detection, authentication, encryption, certificates, and firewalls.

## Practice

Trace what happens when a browser opens a website. Compare TCP with UDP and explain how DNS, IP, and HTTP each contribute.

## Connection to the goals

Networks are a common product-company interview subject and a core teacher-exam subject. Practice explaining protocols through real request flows.
