# Data Structures and Algorithms

## Topics

- Complexity analysis: Big O, time, space, best, average, and worst cases.
- Arrays, strings, hash tables, linked lists, stacks, and queues.
- Trees, binary search trees, balanced-tree concepts, and heaps.
- Graph representations, traversal, shortest paths, and spanning trees.
- Searching, sorting, hashing, and range or interval problems.
- Recursion, divide and conquer, greedy algorithms, and dynamic programming.

## Practice

For each problem, state the input assumptions, choose a structure, outline the algorithm, analyze complexity, implement it, and test normal and edge cases.

## Connection to the goals

This is one of the highest-priority areas for product interviews and a core academic subject for teacher exams. Learn both implementation and the reasoning behind correctness and complexity.
