# Programming Fundamentals

## Topics

- Variables, data types, expressions, operators, input, and output.
- Conditionals, loops, functions, scope, and recursion.
- Arrays or lists, strings, records or dictionaries, and basic file handling.
- Algorithms, pseudocode, flowcharts, tracing, testing, and debugging.
- References, mutability, memory basics, and exceptions.
- Core language features in C and Python; transfer the ideas to one interview language.

## Practice

Write small programs for searching, counting, input validation, number conversion, and text processing. Trace code by hand and explain what each variable contains.

## Connection to the goals

Both tracks depend on clear programming fundamentals. Product interviews require fluency in one language; teacher preparation may test language-specific concepts named by the official syllabus, so check the current notification.
