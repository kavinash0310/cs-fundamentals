# Database Systems and SQL

## Topics

- Relational model, schemas, keys, constraints, and ER diagrams.
- Relational algebra and normalization through common normal forms.
- SQL queries: filtering, joins, grouping, subqueries, and common table expressions.
- Indexes, B-trees, query plans, and basic performance trade-offs.
- Transactions, ACID properties, isolation, locking, and concurrency.
- Relational and non-relational database use cases.

## Practice

Design tables for a small application, write queries with joins and aggregation, normalize a relation, and explain what an index helps and costs.

## Connection to the goals

Databases and SQL are common in product interviews and core academic material for teacher exams. Include both conceptual questions and hands-on query practice.
