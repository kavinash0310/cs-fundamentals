# Database Systems and SQL

A course on relational design, SQL, normalization, storage/indexing, and transaction processing.

## Chapter sequence

| Chapter | Coverage |
|---|---|
| [1. Data models, ER design, and relational model](database-systems-sql/chapter-01-data-models-er-and-relational-model.md) | Entity-relationship design, keys, constraints, relational algebra and calculus |
| [2. SQL queries, joins, and constraints](database-systems-sql/chapter-02-sql-querying-and-constraints.md) | Selection, joins, aggregation, NULL, subqueries, integrity |
| [3. Functional dependencies and normalization](database-systems-sql/chapter-03-functional-dependencies-and-normalization.md) | Attribute closure, keys, 1NF/2NF/3NF/BCNF, lossless decomposition |
| [4. Storage, indexing, and query cost](database-systems-sql/chapter-04-storage-indexing-and-query-cost.md) | Pages, B+ trees, hash indexes, joins and query planning |
| [5. Transactions, concurrency, and recovery](database-systems-sql/chapter-05-transactions-concurrency-and-recovery.md) | ACID, serializability, locks, isolation, deadlocks, WAL/undo/redo |

Practice SQL on paper and a real database. For theory questions, show the dependency or precedence graph rather than only the final label. This covers the official [GATE CS database syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf).
