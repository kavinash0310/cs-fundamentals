# Computer Organization and Architecture

## Topics

- Instruction sets, registers, addressing modes, and machine instructions.
- CPU datapath, ALU, control unit, and instruction execution.
- Pipelining and hazards at a conceptual level.
- Memory hierarchy: cache, main memory, and secondary storage.
- I/O organization, interrupts, DMA, and buses.
- Performance measures and the relationship between hardware and programs.

## Practice

Trace a simple instruction through fetch, decode, and execute. Compare cache and main memory, and explain how an interrupt differs from polling.

## Connection to the goals

This is a core academic subject and supports teacher-exam preparation. Product interviews for systems, embedded, or performance-focused roles may ask deeper questions than general software roles.
