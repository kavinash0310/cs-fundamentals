# Computer Organization and Architecture

This course connects machine instructions to datapath, execution performance, memory, and I/O.

## Chapter sequence

| Chapter | Coverage |
|---|---|
| [1. Performance, instructions, and addressing](computer-organization-architecture/chapter-01-performance-instructions-and-addressing.md) | ISA, instruction cycle, addressing modes, CPU time, Amdahl's law |
| [2. Datapath, ALU, and control](computer-organization-architecture/chapter-02-datapath-alu-and-control.md) | Registers, muxes, ALU, load/store/branch paths, hardwired and microprogrammed control |
| [3. Pipelining and hazards](computer-organization-architecture/chapter-03-pipelining-and-hazards.md) | Pipeline stages, throughput, structural/data/control hazards, stalls and forwarding |
| [4. Cache and memory hierarchy](computer-organization-architecture/chapter-04-cache-memory-hierarchy.md) | Locality, AMAT, direct/set/fully associative mapping, replacement and writes |
| [5. I/O, interrupts, DMA, and review](computer-organization-architecture/chapter-05-io-interrupts-dma-and-review.md) | Polling, interrupts, DMA, buses, memory-mapped I/O, integrated calculations |

Use the diagrams to trace an instruction and the worked problems to calculate CPI, cache fields, and AMAT. The course follows the core in the official [GATE CS syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf).
