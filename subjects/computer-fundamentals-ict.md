# Computer Fundamentals and ICT

## Topics

- What computers do; data, information, applications, and basic computer history.
- Hardware and software; input, output, storage, and peripheral devices.
- Number systems and conversions; binary arithmetic; units of data.
- Character encoding, including ASCII and Unicode.
- Types of memory and storage; basic system startup and files.
- Operating-system purpose, files, folders, and common utilities.
- Internet, web, email, and safe digital practices.

## Practice

Convert values between decimal, binary, octal, and hexadecimal. Identify the role of common components and explain the difference between RAM, storage, an operating system, and an application.

## Connection to the goals

This is a foundation for teacher exams and for explaining technical concepts. It is less central in software interviews than programming, DSA, databases, and systems topics.
