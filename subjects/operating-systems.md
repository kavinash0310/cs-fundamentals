# Operating Systems

Learn OS services and the mechanisms behind processes, scheduling, synchronization, deadlocks, memory, files, and I/O.

## Chapter sequence

| Chapter | Coverage |
|---|---|
| [1. System calls, processes, and threads](operating-systems/chapter-01-system-calls-processes-and-threads.md) | Kernel boundary, process states, context switches, threads, IPC |
| [2. CPU scheduling](operating-systems/chapter-02-cpu-scheduling.md) | FCFS, SJF/SRTF, priorities, Round Robin, metrics and Gantt charts |
| [3. Synchronization and concurrency](operating-systems/chapter-03-synchronization-and-concurrency.md) | Races, critical sections, mutexes, semaphores, monitors, producer-consumer |
| [4. Deadlocks](operating-systems/chapter-04-deadlocks.md) | Necessary conditions, resource graphs, prevention, avoidance, detection |
| [5. Memory and virtual memory](operating-systems/chapter-05-memory-management-and-virtual-memory.md) | Address translation, paging, TLB, page faults, replacement, thrashing |
| [6. Filesystems, I/O, and review](operating-systems/chapter-06-filesystems-io-and-review.md) | Files, allocation, directories, journaling, storage, disk scheduling |

Work every scheduling and page-replacement trace by hand. This covers the core of the official [GATE CS OS syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf).
