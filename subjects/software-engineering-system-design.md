# Software Engineering and System Design

## Topics

- Requirements, decomposition, interfaces, and design trade-offs.
- Modularity, cohesion, coupling, and common architectural styles.
- Testing levels, test cases, debugging, version control, and code review.
- APIs, data modeling, caching, queues, and service boundaries.
- Reliability, availability, scalability, observability, and security basics.
- Low-level object design and high-level distributed-system design.

## Practice

Design a small service from requirements. State assumptions, sketch its API and data model, identify likely bottlenecks, and explain how you would test and monitor it.

## Connection to the goals

Design and software-engineering practice matter in product interviews, especially beyond entry level. For teacher exams, prioritize these only when included in the official syllabus; they are also useful for teaching project work.
